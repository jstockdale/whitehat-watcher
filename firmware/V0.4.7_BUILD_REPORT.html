Changes

nvs_task: reader/writer-agnostic (renamed from nvs_writer)

BEFORE: Task serialized writes only; reads were done inline via direct nvs_get_* calls from any task.
AFTER: Task handles 4 read ops (READ_U64/U8/BLOB/STR) + 5 write ops (U64/U8/BLOB/STR/DEL). ALL NVS reads and writes route through the single FIFO queue. Symbol renamed to nvs_task per John's directive.
Fixes v0.4.6 crash: mqtt_native and ww_feed (PSRAM stacks) panicked on direct NVS reads (cache-disabled).

No fire-and-forget: all ops synchronous

BEFORE: seal_dev_nvs_write_u64/blob/delete were fire-and-forget (enqueue without ACK).
AFTER: All 9 APIs are now _sync and block until the broker completes the op. D4 high-water persist now checks the result — on failure, last_persisted_ is NOT advanced (retry next time).
Callers know if persist succeeded; D4 invariant holds even on NVS errors.

FIFO reliability: never drop, never reject (panic on failure)

BEFORE: Queue-full silently dropped ops; response timeout returned ESP_ERR_TIMEOUT and abandoned the done object.
AFTER: Queue depth 32 (4.5x worst-case in-flight, documented). xQueueSend blocks 5s then PANICS on full. xSemaphoreTake panics on broker timeout. done allocated in INTERNAL RAM (heap_caps). No abandoned flag — response path equally lossless.
John: queue management must never be a failure source; only NVS hardware errors propagate.

NVS stress test (firmware self-test)

BEFORE: No runtime verification of FIFO/serialization.
AFTER: seal_dev_nvs_stress_test(): Phase 1 (ordering: write1->write2->read==write2, no stale reads), Phase 2 (4 PSRAM tasks x 10 iters, isolated keys), Phase 3 (4 tasks, shared key, mutex-paired write->read). Invoked via {"t":"dbg","cmd":"nvs_stress"} (serial only).
Verifies John's requirements on-device.

Migrated all direct NVS call sites

BEFORE: hid_ble (device_name_load), net (load_creds), wakeword (nvs_load/save), mqtt_native (load_mqtt_creds/net), wia1 (wia1_nvs_read) all called nvs_open/nvs_get_* directly.
AFTER: All route through seal_dev_nvs_*_sync(). hid_ble/net/wakeword use extern declarations (no CMake cycles).
Single NVS handle: nvs_task is the ONLY code that calls nvs_open.
