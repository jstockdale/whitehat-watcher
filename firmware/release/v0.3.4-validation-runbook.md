# Watcher v0.3.4 Hardware Validation Runbook

**Date:** 2026-09-24
**Firmware:** v0.3.4 (wake-word + auto-PTT + message display)
**Pre-requisite:** v0.3.4 image built, verified (size/SHA/magic), transferred via MQTT, John clicks "Yes, flash it."

## 1. Boot Check
- [ ] Device boots, display shows status screen
- [ ] `{"t":"dbg","cmd":"version"}` reports fw `0.3.4`
- [ ] `{"t":"dbg","cmd":"mem"}` shows healthy heap/PSRAM
- [ ] No wake-word task running (default OFF)

## 2. Wake-Word Opt-In
- [ ] `{"t":"dbg","cmd":"wakeword"}` reports `on:false`, `phrase:0`, `detections:0`
- [ ] `{"t":"dbg","cmd":"wakeword","on":1}` → reports `on:true`
- [ ] Say "Hi, ESP" clearly → detection counter increments
- [ ] Purple LED → PTT starts (red LED) → recording streams
- [ ] Reboot → `{"t":"dbg","cmd":"wakeword"}` still reports `on:true` (NVS persist)

## 3. Auto-PTT Flow
- [ ] Wake-word triggers PTT without wheel press
- [ ] Speak command → audio streams to host
- [ ] Wheel-click during wake-PTT stops recording early
- [ ] 30-second cap stops long recordings automatically
- [ ] After PTT completes, wake-word resumes (say "Hi, ESP" again → works)
- [ ] No "I2S already in use" errors in logs

## 4. Wheel-Hold PTT (Regression)
- [ ] With wake-word ON: wheel-hold still records normally
- [ ] With wake-word OFF: wheel-hold still records normally
- [ ] No I2S conflicts between wake-word and manual PTT

## 5. Message Display
- [ ] Host sends `{"t":"msg","text":"Hello from Muse"}` → full-screen message
- [ ] Purple AI-thinking LED clears when message arrives
- [ ] Long text wraps and scrolls (wheel = scroll)
- [ ] Wheel-click dismisses → returns to previous UI
- [ ] Message with 4KB text truncates cleanly (no crash)

## 6. Phrase Selection
- [ ] `{"t":"dbg","cmd":"wakeword","phrase":1}` → reports `phrase:1`
- [ ] Log shows "Hey Muse model not available, using interim"
- [ ] Reboot → phrase selection persists

## 7. Timer LED (Regression)
- [ ] Start countdown → completes → LED flashes GREEN (not red)
- [ ] Display shows 00:00.00 until acknowledged

## 8. Stress Test
- [ ] 10x wake → PTT → complete cycles, no leaks
- [ ] `{"t":"dbg","cmd":"mem"}` before/after: heap stable
- [ ] No false wake triggers during normal room audio (5 min)
- [ ] BLE stays connected through all tests

## Known Limitations (v0.3.4)
- Wake phrase is "Hi, ESP" (interim), NOT "Hey Muse"/"Hey Watcher"
- Custom models require Espressif training (weeks)
- Host pipeline (transcribe → Muse → `t:msg`) is separate work
