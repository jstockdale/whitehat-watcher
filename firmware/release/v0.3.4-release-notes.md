## What's New

### Wake-Word Detection (ESP-SR Integration)
- Full ESP-SR 2.5.5 integration with AFE (Acoustic Front End)
- **Default: OFF** (opt-in via `{"t":"dbg","cmd":"wakeword","on":1}`)
- **Interim wake phrase: "Hi, ESP"** (`wn9_hiesp` model)
- I2S0 time-shared cleanly between wake-word (idle) and PTT (recording)
- Detection auto-starts PTT → audio streams to host

### Message Display
- `{"t":"msg","text":"..."}` shows host responses full-screen
- 22pt auto-wrapped text, scrollable via wheel
- Wheel-click dismisses, restores previous UI
- Purple AI-thinking LED clears when response arrives

### Phrase Selection API
- `{"t":"dbg","cmd":"wakeword","phrase":0|1|2}` (0=both, 1=hey_muse, 2=hey_watcher)
- Persisted to NVS, survives reboot
- Currently falls back to interim model with clear log

### Bug Fixes
- Timer countdown completion now flashes GREEN (was red/error)
- PTT I2S lifecycle: fixed data interface leak, forward declaration

## ⚠️ IMPORTANT LIMITATION

**The wake phrases "Hey Muse" and "Hey Watcher" DO NOT work in v0.3.4.**

ESP-SR 2.5.5 does not ship these models. Custom wake-word training requires
Espressif's custom training process (typically weeks). v0.3.4 uses "Hi, ESP"
as the working interim model to validate the full pipeline (detection →
auto-PTT → host → message display).

When Espressif delivers the custom models, they drop into the 2nd WakeNet
slot with no API change (phrase selection is already implemented).
